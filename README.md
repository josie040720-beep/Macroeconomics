# Macroeconomics
# 宏观经济学学习笔记

## 一、学习目标

本目录用于记录宏观经济学课程中的核心概念、经济模型、重要公式及个人学习总结，并逐步结合 Python 开展宏观经济数据分析。

## 二、学习内容

| 主题 | 内容 | 状态 |
|---|---|---|
| 索洛经济增长模型 | 生产函数、资本积累、稳态与经济增长 | 整理中 |
| GDP 与经济增长 | GDP 指标、经济增长率及相关概念 | 待整理 |
| 通货膨胀与失业 | 核心概念、指标与经济含义 | 待整理 |
| 货币政策与财政政策 | 政策工具及其经济影响 | 待整理 |
| 宏观经济数据分析 | 使用 Python 分析经济指标并绘制图表 | 待开展 |

## 三、学习方法

每个主题尽量包含以下内容：

1. **核心概念：** 用自己的语言解释经济学知识。
2. **重要公式：** 记录公式、变量含义及适用条件。
3. **模型逻辑：** 梳理变量之间的关系和推导过程。
4. **图表与例子：** 通过图示或案例理解理论。
5. **Python 实践：** 尝试使用数据和代码辅助理解经济学问题。
6. **学习总结：** 记录关键结论、容易混淆的概念及待解决的问题。

## 四、学习原则

- 以实际课程材料为基础，不把未经学习或验证的内容当作课程结论。
- 区分课程原始内容、个人理解和额外补充。
- 对数据分析结果说明数据来源、分析方法及局限性。
- 随着学习进度持续更新笔记和项目文件。

## 五、项目定位

本目录用于个人学习记录与知识整理，逐步形成宏观经济学理论笔记与数据分析相结合的学习作品集。
